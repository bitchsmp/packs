# Mythicmobs and MythicCrucible packs
This repository stores packs made for Minecraft Bukkit/Spigot/Paper plugin "Mythicmobs" and "MythicCrucible"

Packs are mainly made by Dueris

## Note:
For AttachableWeapon pack, remember to copy the stats.yml and paste it in the main /plugin/MythicMobs folder, via init.sh or init.bat

## Dependencies:
1. Minecraft Paper Server
   
   - Download here: https://papermc.io/downloads/paper

   - Current Version: 1.21.11
   


2. MythicMobs & MythicCrucible Plugins

   - Plugins Offical Website: mythiccraft.io

   - Current Version: Latest Dev Build

   - Direct Download Links:

     - MythicMobs: [5.11.2-20260117.083954-17](https://mvn.lumine.io/repository/maven/io/lumine/Mythic-Dist/5.11.2-SNAPSHOT/Mythic-Dist-5.11.2-20260117.083954-17.jar)
     - MythicCrucible: [2.4.0-20260117.031427-9](https://mvn.lumine.io/repository/maven/io/lumine/MythicCrucible/2.4.0-SNAPSHOT/MythicCrucible-2.4.0-20260117.031427-9.jar)


3. LibsDisguise Plugin

   - Current Version: Latest Stable Build

   - Download Link: https://ci.lib.co.nz/job/LibsDisguises/lastStableBuild/artifact/target/LibsDisguises.jar
